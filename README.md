# PriceWatch AZ

Бесплатный адаптивный сайт для истории цен на технику. В комплекте 6 моделей Bosch из Baku Electronics. **Цены не предзаполнены:** они появляются только после подтверждённой проверки.

## Запуск за 5 минут

1. Загрузите **содержимое** этой папки (не ZIP целиком) в корень публичного GitHub-репозитория `pricewatch-az`: `Add file` → `Upload files` → `Commit changes`. Папку `.github` нужно сохранить с вложенным файлом `.github/workflows/daily.yml`. Если загрузка скрытых папок неудобна, создайте файл workflow через `Add file` → `Create new file` и укажите полный путь.
2. `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` → `main` → `/(root)` → `Save`.
3. `Actions` → `Daily price check` → `Run workflow` → `Run workflow`. Разрешите Actions, если GitHub попросит.
4. Откройте сайт: `https://mrruslanazizov96-hash.github.io/pricewatch-az/` (публикация может занять несколько минут).
5. Проверьте `Actions` → лог запуска. При ошибке сбора данные останутся без цены, это ожидаемо, пока не настроим конкретный магазин.

## Другие магазины

В `products.json` у каждого товара есть массив `offers`. Добавьте **точную ссылку на ту же модель** с названием магазина, например:

```json
{"store":"Kontakt","url":"https://kontakt.az/ССЫЛКА-НА-ТОВАР"}
```

Поддерживаемые домены перечислены в `scrape.py` (`ALLOWED`). Это **не означает**, что извлечение цен уже проверено для каждого сайта: сейчас программа распознаёт JSON-LD `Product`/`Offer` с совпадающей моделью. Некоторые сайты отдают цены через JavaScript, блокируют ботов или не публикуют JSON-LD. Тогда нужно добавить отдельный адаптер, не обходя защиту сайта. Проверяйте правила сайтов.

## Обновления

GitHub Actions запускается примерно в 09:15 по Баку (05:15 UTC); запуск может задерживаться. `workflow_dispatch` позволяет запустить проверку вручную. Результаты сохраняются в `data/history.json`. Неудачные проверки сохраняются со статусом и **не превращаются в нулевую цену**. График появляется после двух успешных наблюдений. Если наблюдение старое, дата видна в карточке.

## Ограничения

- Пока нет Telegram-уведомлений и редактирования товаров прямо с сайта.
- Это первая рабочая версия, а не гарантия автоматического получения цен со всех магазинов.
- GitHub Pages публикует товары и историю публично. Не размещайте личные данные и токены.
- Бесплатные лимиты и правила GitHub могут меняться.
